# Student Event Registration Formatter

## Description

This Python program collects student event registration details, including the student's first name, last name, section, event name, and event date. It formats the input text and displays the registration information in a clean and readable format.

## Language Used

Python

## String Feature Used

- `strip()` – Removes unnecessary spaces at the beginning and end of text.
- `title()` – Formats names and event titles into proper title case.
- `upper()` – Converts text into uppercase letters.

## Date/Time Feature Used

`datetime` – Used to create and display the event date in a readable format.

## Version History

- **Version 1:** Basic input and output.
- **Version 2:** Added string formatting methods to clean and format text.
- **Version 3:** Added date formatting using the `datetime` module.
